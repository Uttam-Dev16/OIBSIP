# To-Do Web App

A simple and responsive To-Do Web App built using HTML5, CSS3, and Vanilla JavaScript.

## Features

- Add new tasks
- View pending tasks
- Mark tasks as complete
- Move completed tasks back to pending
- Edit tasks inline
- Delete tasks
- Display pending and completed task counts
- Empty-state messages
- Save tasks using browser localStorage
- Show task creation timestamp
- Responsive layout for desktop and mobile screens

## Technologies Used

- HTML5
- CSS3
- Vanilla JavaScript
- Browser LocalStorage

## How to Run

1. Open the project folder.
2. Open `index.html` in a web browser.
3. Enter a task in the input field.
4. Click `Add Task` to create a pending task.
5. Use the available buttons to complete, edit, or delete tasks.

## Data Persistence

Tasks are stored in the browser's localStorage, so they remain available after refreshing the page.
