# Calculator

A simple and responsive calculator built using HTML5, CSS3, and Vanilla JavaScript.

## Features

- Addition, subtraction, multiplication, and division
- Number input from 0 to 9
- Decimal number support
- Clear button
- Backspace button
- Equals button for calculation
- Operator chaining
- Division-by-zero error handling
- Responsive layout using CSS Grid
- Button interactions handled with JavaScript event listeners

## Technologies Used

- HTML5
- CSS3
- Vanilla JavaScript
