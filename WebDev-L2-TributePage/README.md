# Tribute Page

A responsive tribute page dedicated to Dr. A. P. J. Abdul Kalam, built using HTML5 and CSS3.

## Features

- Hero section with title and tagline
- Prominent tribute image
- Original biographical content
- Timeline of important milestones
- Inspirational quote section
- Responsive layout for desktop and mobile screens
- Multiple background colors
- Serif and sans-serif typography

## Technologies Used

- HTML5
- CSS3
